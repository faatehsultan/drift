# Security Policy

Drift touches sensitive things (your clipboard, calendar, YouTube session cookies and a local server for Claude Code approvals), so security reports are taken seriously.

## Reporting a vulnerability

Please **don't open a public issue**. Use GitHub's private reporting instead: **Security → Report a vulnerability** on this repository.

Include what you found, how to reproduce it and the Drift version. You'll get a reply as soon as possible, and fixes ship through the normal auto-update.

## Supported versions

Only the latest release gets security fixes.
