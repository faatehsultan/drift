FAQ

Questions, answered.

Is it really free?

Yes, and open source under the GPL-3.0. Use everything, read the code, or help build it on GitHub.

Does it need a Mac with a notch?

No. On other Macs and external displays, Drift draws a slim black pill at the top center that works the same way.

macOS says "Drift Not Opened". What do I do?

Click Done, then open System Settings → Privacy & Security, scroll down and click Open Anyway. You only need to do this once. Or install with one Terminal command, which skips the warning: curl -fsSL https://faatehsultan.github.io/drift/install.sh | bash. See the guide.

Do I need a YouTube Music account?

No. Search and playback work without one. Sign in to see your likes, playlists and mixes.

What happens if music is playing in my browser and in Drift?

Only one plays at a time. Starting something in Drift pauses the other app, and starting the other app pauses Drift. When both have something loaded, Drift's own player stays in front. You can turn this off in Settings → General → Media.

How do updates work?

Drift checks once a day and offers new versions with release notes. You can also use Check for Updates… in the menu.

How do Claude Code approvals work?

In Settings → Integrations, click Install hook. Permission requests then show in the notch. If Drift isn't running, Claude Code asks in the terminal as usual.
